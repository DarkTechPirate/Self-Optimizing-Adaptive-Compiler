# First 10 Users Plan

Goal: 10 real people run Nyx on a real workload.

## What to ask each user
- Does this actually help you?
- What language do you want support for?
- Where would you use this?

## Fast interview script
1. What workload did you test?
2. Did you get measurable speedup?
3. Was the output easy to trust?
4. Which part felt confusing?
5. What would make this production-ready for you?

## Tracking sheet columns
- User
- Workload type
- Input language
- Baseline time
- Optimized time
- Speedup ratio
- Reused history (yes/no)
- Would use again (yes/no)
- Requested feature
